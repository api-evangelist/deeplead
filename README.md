Deeplead finds B2B customers and runs cold email outreach to them. It searches local businesses, companies and people, finds decision makers with verified work emails and phone numbers, and sends personalized campaigns from warmed-up inboxes with one inbox for every reply. The same data is available to developers and AI agents through a REST API with an OpenAPI 3.1 contract and a remote MCP server, both authenticated with an API key or OAuth.

**Areas:** Company · Lead Generation · Cold Email · Artificial Intelligence · Sales Automation
